# โมเดลภาษาขนาดใหญ่ (LLM) และการเขียน Prompt

โมเดลภาษาขนาดใหญ่ (Large Language Model: LLM) คือโมเดลภาษาแบบ Transformer ที่มีพารามิเตอร์จำนวนมาก ตั้งแต่หลักพันล้านไปจนถึงหลักล้านล้านตัว ฝึกล่วงหน้าด้วยข้อความปริมาณมหาศาลเพื่อทำนายโทเคนถัดไป ตัวอย่างโมเดลตระกูล LLM ได้แก่ GPT ของ OpenAI, Claude ของ Anthropic, Gemini ของ Google และ Llama ของ Meta ซึ่งเป็นโมเดลแบบเปิดน้ำหนัก (Open-weight)

## ขั้นตอนการฝึก LLM

1. Pre-training ฝึกให้ทำนายโทเคนถัดไปจากข้อความจำนวนมหาศาล
2. Supervised Fine-tuning (SFT) ฝึกต่อด้วยคู่คำสั่งและคำตอบที่มนุษย์เตรียมไว้ ให้โมเดลทำตามคำสั่งได้
3. Alignment เช่น RLHF (Reinforcement Learning from Human Feedback) ใช้ความชอบของมนุษย์ปรับให้คำตอบเป็นประโยชน์และปลอดภัย

## Prompt Engineering

Prompt Engineering คือการออกแบบคำสั่งที่ส่งให้ LLM เพื่อให้ได้ผลลัพธ์ตามต้องการ เทคนิคสำคัญได้แก่
- Zero-shot Prompting สั่งงานโดยไม่ให้ตัวอย่าง
- Few-shot Prompting ให้ตัวอย่างคู่อินพุตและเอาต์พุตไม่กี่ตัวอย่างเพื่อแสดงรูปแบบที่ต้องการ
- Chain-of-Thought (CoT) ให้โมเดลแสดงขั้นตอนการคิดทีละขั้นก่อนตอบ ช่วยให้งานที่ต้องใช้เหตุผลแม่นยำขึ้น
- Role Prompting กำหนดบทบาทให้โมเดล เช่น "คุณเป็นผู้ช่วยด้านกฎหมาย"
- กำหนดรูปแบบเอาต์พุต เช่น ให้ตอบเป็น JSON หรือความยาวไม่เกินสามประโยค

## พารามิเตอร์ที่ควบคุมการสร้างข้อความ

Temperature ควบคุมความสุ่มของคำตอบ ค่าต่ำ (ใกล้ 0) ให้คำตอบคงที่และตรงไปตรงมา เหมาะกับงานตอบจากเอกสาร ค่าสูงให้คำตอบหลากหลายและสร้างสรรค์ Top-p (Nucleus Sampling) เลือกโทเคนจากกลุ่มที่มีความน่าจะเป็นสะสมถึงค่าที่กำหนด และ Max Tokens จำกัดความยาวของคำตอบ

## Groq API

Groq เป็นบริการที่ให้เรียกใช้ LLM แบบเปิดผ่าน API ด้วยความเร็วสูง โดยใช้ชิปเฉพาะทางที่เรียกว่า LPU (Language Processing Unit) ไลบรารี Python ชื่อ groq มีรูปแบบการเรียกคล้ายกับ OpenAI คือ client.chat.completions.create โดยส่งรายการข้อความที่มี role เป็น system, user และ assistant ต้องใช้ API Key ซึ่งห้ามเขียนไว้ในโค้ดโดยตรง ควรเก็บในตัวแปรสภาพแวดล้อมหรือ Secrets ของแพลตฟอร์ม

## ข้อจำกัดของ LLM

LLM อาจเกิด Hallucination ไม่รู้ข้อมูลหลังวันตัดข้อมูล และมีความยาวบริบทจำกัด การให้ข้อมูลอ้างอิงผ่าน RAG และการสั่งให้ปฏิเสธเมื่อไม่แน่ใจ ช่วยลดปัญหาเหล่านี้ได้

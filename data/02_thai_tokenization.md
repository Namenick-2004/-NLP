# การตัดคำภาษาไทย (Thai Word Tokenization)

การตัดคำ (Word Tokenization) คือกระบวนการแบ่งข้อความออกเป็นหน่วยย่อยที่เรียกว่าโทเคน (Token) ซึ่งมักเป็นคำ ภาษาอังกฤษมีช่องว่างคั่นคำอยู่แล้ว จึงตัดคำได้ง่ายด้วยการแยกตามช่องว่าง แต่ภาษาไทยเขียนต่อเนื่องกันโดยไม่มีช่องว่างระหว่างคำ ทำให้การตัดคำเป็นขั้นตอนสำคัญและมีความยากกว่า

## ตัวอย่างความกำกวมของการตัดคำ

ประโยค "ตากลมตากลม" สามารถตัดได้หลายแบบ เช่น "ตา กลม ตาก ลม" ซึ่งให้ความหมายต่างกันโดยสิ้นเชิง อีกตัวอย่างคือ "ไปหาคนข้างบ้าน" ที่อาจตัดผิดเป็น "ไป หา คน ข้าง บ้าน" หรือ "ไป หา คน ข้างบ้าน" การตัดคำที่ผิดพลาดส่งผลต่อโมเดลในขั้นตอนต่อไปโดยตรง

## เครื่องมือตัดคำภาษาไทยยอดนิยม

ไลบรารีที่นิยมที่สุดคือ PyThaiNLP ซึ่งเป็นไลบรารีภาษา Python โอเพนซอร์สสำหรับ NLP ภาษาไทย ฟังก์ชัน word_tokenize ของ PyThaiNLP รองรับหลายเอนจิน (engine) ได้แก่
- newmm เป็นเอนจินค่าเริ่มต้น ใช้อัลกอริทึม Maximum Matching ร่วมกับ Thai Character Cluster ทำงานเร็วและแม่นยำในระดับที่ใช้งานได้ดี
- longest ใช้หลักการจับคู่คำที่ยาวที่สุดตามพจนานุกรม
- deepcut ใช้โครงข่ายประสาทเทียมแบบ CNN ให้ความแม่นยำสูงแต่ช้ากว่า
- attacut ใช้โครงข่ายประสาทเทียมที่เร็วกว่า deepcut พอสมควร

ตัวอย่างการใช้งาน: from pythainlp.tokenize import word_tokenize แล้วเรียก word_tokenize("ฉันรักภาษาไทย", engine="newmm") จะได้ลิสต์ของคำ เช่น ["ฉัน", "รัก", "ภาษาไทย"]

## การตัดประโยคภาษาไทย

ภาษาไทยไม่มีเครื่องหมายจบประโยคที่ชัดเจนเหมือนภาษาอังกฤษที่มีจุด (.) PyThaiNLP จึงมีฟังก์ชัน sent_tokenize สำหรับตัดประโยค โดยเอนจินค่าเริ่มต้นคือ crfcut ซึ่งใช้โมเดล CRF ที่เรียนรู้จากข้อมูลจริง การตัดประโยคมีประโยชน์ต่อการแบ่งเอกสารเป็นชิ้นย่อย (Chunking) ในระบบ RAG

## การตัดคำแบบ Subword

โมเดลภาษาสมัยใหม่มักไม่ใช้การตัดคำตามพจนานุกรม แต่ใช้การตัดแบบ Subword เช่น BPE, WordPiece และ SentencePiece ซึ่งแบ่งคำที่พบน้อยออกเป็นหน่วยย่อย ช่วยลดปัญหาคำที่ไม่รู้จัก (Out-of-Vocabulary: OOV) โมเดลอย่าง WangchanBERTa ใช้ SentencePiece ในการแบ่งข้อความภาษาไทย
